# Эксперимент SoftSearch

60 запросов, шесть типов, два режима, лимит 4. Три прогревочных запроса на режим; порядок режимов чередуется; `log: false`. Все 120 измеряемых ответов успешны. Ожидаемый коммит — `0174ad1`, автоматическая проверка версии не выполнена (см. metadata.json).

- `summary.csv`, `per_query.csv`, `by_query_type.csv` — оригинальные отчёты по полю `products`.
- `summary_by_method_field.csv`, `by_query_type_results.csv` — дополнительная оценка полной выдачи `results` (для baseline используется `products`). Отдельный блок популярных рекомендаций исключён.
- `benchmark_search.py` — скрипт исходного прогона. Установка: `python -m pip install requests pandas`. Запуск с предоставленным эталоном: `python benchmark_search.py --csv gold_input.csv --out benchmark_run`.
- [Графики](../graphs/) — три изображения из аналитического архива.

Обычная релевантность: совпадение ID товара или категории. Строгая: совпадение ID при наличии эталонного ID, иначе категории. Precision@4 = число релевантных результатов / 4; HitRate@4 = доля запросов с хотя бы одним релевантным результатом. Наличие четырёх товаров не доказывает их релевантность.

Для полной воспроизводимости требуется исходный `gold_input.csv` из архива команды. Он и полные сырые ответы не включены в пакет для публикации до подтверждения разрешения на распространение данных кейса. Скрипт прогона оценивает основные результаты; дополнительная таблица полной выдачи получена при последующей обработке сохранённых ответов. Ручная оценка слабых запросов ещё не завершена. Метрики не являются измерением продаж или реальной конверсии.
